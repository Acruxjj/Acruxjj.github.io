<div class="research-topic">
  <h2>Spectral Window Dependence in Stellar Parameter Inference of M Dwarfs</h2>

  <p>
    <span data-lang="en">
      This research project investigates how spectral-window selection affects the inference of stellar parameters in M dwarfs. Synthetic spectra are generated using Korg and analyzed with one-dimensional Convolutional Neural Networks (1D CNNs) to estimate effective temperature, surface gravity, and metallicity.
    </span>
    <span data-lang="pt">
      Este projeto de pesquisa investiga como a seleção de janelas espectrais afeta a inferência de parâmetros estelares em anãs M. Espectros sintéticos são gerados com Korg e analisados por Redes Neurais Convolucionais unidimensionais (1D CNNs) para estimar temperatura efetiva, gravidade superficial e metalicidade.
    </span>
  </p>

  <p>
    <strong>Technologies:</strong> Python, Korg, TensorFlow/Keras, NumPy, Pandas, Matplotlib.
  </p>

  <h2>Stellar Data Explorer</h2>

  <p>
    <span data-lang="en">
      A data exploration application developed to organize, query, analyze, and visualize stellar datasets. The project uses a relational SQLite database and provides interactive visualizations through Streamlit, alongside modular Python code and automated tests.
    </span>
    <span data-lang="pt">
      Uma aplicação de exploração de dados desenvolvida para organizar, consultar, analisar e visualizar conjuntos de dados estelares. O projeto utiliza um banco de dados relacional SQLite e oferece visualizações interativas com Streamlit, além de código Python modular e testes automatizados.
    </span>
  </p>

  <p>
    <strong>Technologies:</strong> Python, SQL, SQLite, Pandas, NumPy, Matplotlib, Streamlit, Pytest.
  </p>
